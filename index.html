Tuntunan & Tata Cara
Instal Ulang Windows

Mawujudkeun sistem komputer anyar kalawan rapih, aman, tur lancar. Panduan step-by-step terstruktur mawa gaya budaya Nusantara modern kanggo Windows 10 & 11.

Progres Instalasi Anda

0 dari 5 Langkah Selesai

I

Piranti & Beberes (Syarat Persiapan)

Cawiskeun bahan-bahan di handap sateuacan ngamimitian proses instal ulang.

1. Flashdisk Minimal 8GB

Siapkan media penyimpanan USB kosong dengan kapasitas minimal 8GB. Pastikan data di dalam flashdisk sudah dipindahkan karena akan diformat total.

2. ISO Windows & Rufus Tool

Unduh file Master ISO resmi Windows 10/11 langsung dari situs Microsoft, serta software installer portable Rufus / Media Creation Tool.

3. Backup Data Penting

Amankan dokumen penting di Drive C (Desktop, Downloads, Documents) ke Harddisk Eksternal / Cloud. Sangkan salira selamet tur teukagok pas formatting disk.

II

Piwulang (Langkah demi Langkah)

Centang setiap kotak pituduh di bawah ini jika Anda telah mempraktekkannya.

1

Membuat Bootable Flashdisk (Rufus)

1. Colokkan flashdisk minimal 8GB ke Laptop / PC Anda.

2. Buka aplikasi Rufus yang telah diunduh.

3. Pilih drive Flashdisk Anda pada menu Device.

4. Klik tombol SELECT lalu cari file ISO Windows 10/11 Anda.

5. Pada pilihan Partition Scheme:

  • Pilih GPT (Sangat direkomendasikan untuk komputer keluaran terbaru / UEFI).
  • Pilih MBR (Untuk komputer lama / BIOS Legacy).

6. Klik START, tekan OK saat muncul konfirmasi hapus data. Tunggu indikator status berubah menjadi warna hijau tulisan READY.

2

Mengatur BIOS / UEFI Boot Priority

1. Tancapkan Flashdisk bootable yang sudah dibuat ke port USB komputer yang mati.

2. Nyalakan komputer, lalu segera tekan tombol BIOS secara berulang-ulang sebelum masuk Windows (Tombol tergantung merk: F2, F12, DEL, atau ESC).

3. Masuk ke tab menu Boot atau Boot Priority.

4. Pindahkan posisi USB Flashdisk / UEFI USB ke urutan teratas (Nomor 1 Boot Device).

5. Tekan tombol F10 untuk menyimpan konfigurasi dan pilih Yes / Save Changes and Exit. Komputer akan merestart otomatis.

3

Proses Instalasi Utama Windows & Partisi Disk

1. Setelah reboot, layar instalasi Windows akan muncul. Atur Time and Currency format ke Indonesian (Indonesia), lalu klik Next > Install Now.

2. Jika diminta lisensi, pilih "I don't have a product key" (bisa diaktivasi nanti).

3. Pilih versi Windows (contoh: Windows 10/11 Pro) lalu centang persetujuan lisensi (I accept the license terms).

4. Pada jenis instalasi, pilih Custom: Install Windows only (advanced).

5. BAGIAN PENTING (PARTISI DISK):

  • Pilih Partisi System Lama (Drive C / System) dan partisi kecil bawaan sistem (System Reserved/EFI/MSR).
  • Klik tombol Format atau Delete pada partisi C lama tersebut hingga menjadi Unallocated Space.
  • Hati-hati: Jangan menghapus partisi tempat Anda menyimpan Data Pribadi (biasanya Drive D / Local Disk D).
  • Pilih Unallocated Space tersebut lalu klik Next.

6. Tunggu proses Copying & Installing files hingga selesai 100%. Komputer akan restart otomatis. Cabut Flashdisk Anda saat komputer melakukan restart pertama kali.

4

Konfigurasi Awal System (OOBE)

1. Saat masuk ke tampilan layar penyetelan awal (OOBE): Pilih Wilayah Indonesia dan Keyboard Layout US.

2. Koneksi Jaringan: Jika tidak ingin ribet login Microsoft Account pada Windows 11, pilih "I don't have internet" atau jalankan command bypass jika diperlukan.

3. Masukkan Nama Pengguna (Username) untuk Laptop/PC Anda dan tentukan Kata Sandi (Password) jika dibutuhkan.

4. Pada pengaturan Privacy Settings, sesuaikan atau matikan lokasi/diagnostic data sesuai preferensi Anda untuk kinerja lebih cepat, lalu klik Accept.

5. Tunggu beberapa saat hingga Desktop Windows Anda berhasil terbuka sempurna.

5

Pasca-Instal (Driver & Software Esensial)

1. Hubungkan koneksi internet WiFi / LAN.

2. Buka Settings > Update & Security > Windows Update, lalu klik Check for updates agar driver VGA, Sound, & Chipset terunduh otomatis.

3. Lakukan aktivasi lisensi Windows Anda secara legal.

4. Pasang software esensial (Google Chrome, WinRAR, MS Office, PDF Reader, & Anti Virus).

III

Pituduh Perintah (Code Snippets)

Perintah cepat PowerShell / CMD pikeun optimasi jeung ngecek status sistem.

slmgr.vbs /xpr
Bypass Koneksi Internet Windows 11 OOBE (Shift + F10 saat setup) 
OOBE\BYPASSNRO
Perbaikan File Sistem Rusak (PowerShell Admin) 
sfc /scannow
IV

Pitakon (FAQ / Pertanyaan Umum)

Hal-hal anu sering ditatanyakeun ngeunaan proses instal ulang Windows.

Henteu (Tidak), asalkan Anda hanya menghapus/menformat partisi Drive C (System) saat proses instalasi. Data di Drive D atau E akan tetap aman dan terisolasi.
Pilih GPT untuk laptop/PC modern yang menggunakan mode UEFI/Windows 11. Pilih MBR jika komputer Anda tergolong lama (keluaran di bawah tahun 2014 / Legacy BIOS).
Pastikan fitur Secure Boot diatur ke Disabled pada menu BIOS, serta periksa kembali apakah skema pembuatan bootable (GPT/MBR) sudah cocok dengan sistem BIOS laptop Anda.
